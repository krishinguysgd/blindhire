# What Is BlindHire?

## Core Idea

BlindHire is:

> a privacy-first hiring platform where candidates are evaluated based on skills, experience, and verified reputation — WITHOUT exposing personal identity initially.

Companies do NOT see:

* gender
* age
* race
* country
* name
* photo
* university

until later stages.

Instead they see:

* skills
* projects
* reputation
* verified achievements
* interview performance

This creates:

> fairer, privacy-preserving hiring.

---

# The Problem We Are Solving

Modern hiring is broken.

Recruiters unconsciously judge candidates based on:

* name
* accent
* location
* college
* age
* gender
* ethnicity

This creates:

* hiring bias
* discrimination
* unfair opportunities

ALSO:
job seekers overshare huge amounts of personal data online.

Resumes contain:

* address
* phone number
* identity details
* full work history
* personal information

And this data gets:

* leaked
* sold
* scraped
* abused

# Our Solution

BlindHire changes hiring from:

> identity-first

to:

> skill-first.

Using encrypted computation and selective disclosure:

* candidates stay anonymous initially

* identity unlocks only after mutual interest

This creates:

* fairer hiring
